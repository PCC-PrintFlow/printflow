# PCC PrintFlow

Order, production, invoicing, costing, catalog, craft fair and creator app for **Pa Chuck Creations, LLC** (10819 Walnut St., Leo, IN 46765).

**Installed app:** https://pcc-printflow.github.io/printflow/ (install from Chrome/Edge on the PC, or Safari → Add to Home Screen on the iPad).

## How this repository is laid out

| Path | What it is |
| --- | --- |
| `index.html`, `sw.js`, `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` | The **built app** that GitHub Pages serves. Generated by `dev/build.py`. Don't edit by hand. |
| `dev/printflow.html` | **The source.** One self-contained HTML/JS file. It also runs as-is inside Claude. |
| `dev/build.py` | Rebuilds the root app files from the source (`python3 dev/build.py`, needs Pillow). |
| `dev/assets/` | Logo images the build uses for the app icons. |
| `dev/tests/` | Browser tests with made-up sample data (`python3 dev/tests/run_all.py`, needs Playwright). |
| `dev/docs/PROJECT.md` | Full description of every feature, data format and design decision. Start here. |

## Making a change

1. Edit `dev/printflow.html`.
2. `python3 dev/build.py`
3. `python3 dev/tests/run_all.py`
4. Commit and push (or upload the changed files on github.com). Each device picks up the new version the next time PrintFlow opens with internet.

## Data

No business data is ever stored here. Each device keeps its own data in the browser. **Push / Pull** in Settings → Sync between devices copies it through the **private** repository `pcc-printflow/printflow-data`.
